# TripCraft
Smart Travel Planner & Experience Explorer — BCSE203E Digital Assignment X.

Run:
```bash
npm install
npm run dev
```

Features: destination explorer, search/filter, trip management, itinerary management, automatic budget calculation, React Router, Hooks, Props, PropTypes, reusable components and Open-Meteo API integration.
